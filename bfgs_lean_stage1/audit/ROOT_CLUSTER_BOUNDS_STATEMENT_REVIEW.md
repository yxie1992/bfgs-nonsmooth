# Actual root bounds and multiplicity clusters

Frozen scope: eight source modules, 23 explicit theorem declarations, four exact contracts. Final import: `RootClusterBoundsTargets`. The accompanying verifier performs fresh pinned compilation of every source, prints every actual theorem type and its transitive axioms, checks all four contracts with `Meta.isDefEq`, and verifies the frozen source hashes. No external arithmetic results are used.

This is an analytic prerequisite for Module A's still-open finite semialgebraic path decomposition. It is not the decomposition theorem, nor an additional hypothesis inserted into that theorem.

1. `ParameterRootBounds` identifies the actual Cauchy root bound of a coefficient-specialized polynomial with a continuous finite coefficient formula where the symbolic leading coefficient specializes to a nonzero value. It derives an actual uniform neighborhood bound on every root. Empty root sets and constant polynomials are included.
2. `ParameterRootPersistence` proves joint continuity of actual polynomial evaluation, uniform nonvanishing on a fixed compact set, and upper semicontinuity of the actual root set. The latter uses the compact complement of the supplied open root neighborhood inside the derived Cauchy bound.
3. `RootMultiplicityRolle` defines `rootsIn` as the actual roots multiset's finite support filtered by the supplied set, and `rootWeightIn` as the sum of the actual polynomial root multiplicities there. Rolle's theorem supplies derivative roots between consecutive distinct roots inside any order-connected set. Combining that interleaving bound with the actual derivative multiplicity inequality gives `weight(p,I) ≤ weight(p',I)+1`.
4. `RootMultiplicityCluster` iterates the preceding inequality. Nonvanishing of the actual m-th derivative throughout the interval implies total root multiplicity at most m. At every point of a nonzero base fiber, the derivative of order equal to the actual base multiplicity is nonzero. Compact uniform nonvanishing therefore gives a fixed small interval whose root weight in every sufficiently near fiber is bounded by that multiplicity. A nonroot center has multiplicity zero and is included.
5. `ParameterDegreeRootPersistence` handles degree drops by an actual coefficient prefix. It proves uniform bounds and upper semicontinuity on compared parameters whose actual degree is at most the base degree; no ambient constant-degree neighborhood is assumed. A nearby identically zero specialization satisfying that degree restriction is excluded by the derived nonzero leading coefficient of the prefix.
6. `FiniteRootNeighborhoods` chooses a single arbitrarily small positive radius for a finite set of root centers, subordinate to every supplied positive radius and separating all closed intervals. The empty family is included. It also proves monotonicity of actual root weight under set inclusion.
7. `ParameterRootClusters` combines these facts. Before selecting a nearby parameter, it chooses a fixed positive radius below any prescribed epsilon. The corresponding closed intervals around every actual distinct base root are pairwise disjoint. For every sufficiently near parameter satisfying the actual degree bound, all actual roots lie in the union of the open intervals and each closed interval carries no more total multiplicity than its base root. It also proves that the whole-line root weight equals the actual roots multiset cardinality.
8. `RootClusterBoundsTargets` exports exact bound, Rolle, local multiplicity, and simultaneous cluster contracts.

The theorem deliberately does not assume or conclude that every cluster stays occupied. That requires conservation of total real-root multiplicity. With both total multiplicity and distinct-root count fixed, the planned next finite conservation argument yields exactly one root per cluster and preservation of its multiplicity. Ordered root continuity, locally smooth branches, and the finite graph/band induction remain subsequent obligations.

A necessary mathematical distinction: fixing only degree and distinct-root count does not guarantee delineability. For example, `((t+1)^2-s)*((t-1)^2+s)` has two distinct real roots at s=0 and also for sufficiently small positive s, but the positive-s roots both approach −1. The planned parameter strata additionally fix total real-root multiplicity. This example is explanatory here, not an audited theorem of this tranche.
