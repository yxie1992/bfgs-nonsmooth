# Actual polynomial root signs and local Tarski–Cauchy identity

This six-file tranche proves the local analytic portion of the general arbitrary-degree sign-determination route in `GENERAL_PROJECTION_PATH_PLAN.md`. It does not provide the signed-remainder-chain computation of the index, a finite parameter decision tree, general polynomial projection, or finite smooth cell/path decomposition. Module A's general semialgebraic conclusion remains open.

`PolynomialRootSigns` removes exactly the actual root multiplicity from a nonzero real polynomial using its monic polynomial quotient. The remaining factor is nonzero at the base point, and the exact factorization is proved by applying actual polynomial evaluation to the division identity. Its locally constant sign yields the actual right-hand sign and the left-hand sign multiplied by `(-1)^multiplicity`. No simple-root, square-free or nonroot premise is imposed; multiplicity zero is included.

`PolynomialLogDerivative` differentiates the actual factorization and proves the normalized logarithmic-derivative identity. The limit of `(x-a)*p'(x)/p(x)` along the punctured neighborhood is exactly the natural root multiplicity, cast into the reals. The weighted limit is that positive integer times the actual weight value. Denominator nonvanishing is derived near the root from the factorization; division by a vanishing value at the puncture is never cancelled. The pointwise total-division convention at the puncture does not affect the punctured limit.

`PolynomialLogPoles` obtains actual one-sided infinite limits from the normalized limit and the inverse of `x-a`. A positive weight at a denominator root gives a right limit +∞ and left limit −∞; a negative weight reverses both signs. Nonzero polynomial and actual root hypotheses derive strictly positive multiplicity, including arbitrary repeated roots.

`PolynomialLogCancellation` proves a finite punctured limit when the weight also vanishes at the denominator root. It uses actual monic division of the weight by `X-C a`; this branch does not assume a generic nonzero weight or discard coincident roots. The signed local index is defined by actual opposite one-sided infinite limits, with value zero otherwise. Incompatible infinite/finite limits prove the cancelled branch has index zero. Thus the weighted logarithmic derivative has local index exactly the integer cast of the actual weight sign, independent of the positive root multiplicity.

`TarskiLocalIndex` defines the global rational Cauchy index as the sum of these actual local jumps over the actual distinct denominator roots. This is the full-line integer jump convention; endpoints at poles of a finite interval are not part of this API. The query is the integer sum of actual signs over the same distinct root set. The theorem equating the query to the rational index of `q*p'/p` is proved term by term using the local limits. A separate finite identity proves the query equals the number of positive weights minus the number of negative weights; constant one counts distinct roots, and constant zero gives zero. These definitions do not hide an index-computation oracle. In particular, the equality alone does not make the query a semialgebraic function of the coefficients: deriving the finite signed-remainder computation and handling parameter degree branches are still required.

The four exact contracts are `PolynomialOneSidedSignsTarget`, `PolynomialLogarithmicResidueTarget`, `WeightedLogarithmicPoleTarget` and `TarskiCauchyLocalIdentityTarget`. The last two explicitly retain the weight-zero and arbitrary-multiplicity cases. The proof uses only actual polynomial evaluation, derivatives, monic division, finite real roots and actual order-topological limits.
