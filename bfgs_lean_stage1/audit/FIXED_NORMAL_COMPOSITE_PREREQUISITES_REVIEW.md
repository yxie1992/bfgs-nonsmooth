- `FixedNormalSegments` completes the literal U.2 source description: compact convex nonempty actual subdifferentials with common projection lie on an actual closed scalar interval, genuine nondifferentiability derives strict endpoint separation, and the actual affine hull equals the full normal affine line. `nonsmooth_subdifferential_parallel_segment` states equality with mathlib's actual `segment`, not an informal label. No assumed nonempty/distinct subgradients are added to the final objective statement.
- `FixedNormalCocoercivity` proves a smooth-open-set extension of the already checked local descent/Bregman proof. The smooth region may be disconnected, but the objective is globally convex, so the required supporting inequalities remain valid across its components. Compactness supplies the local test-ball constants. The cutoff-strip theorem derives that both sufficiently close endpoints belong to one compact subset away from all interfaces, then applies this global-support argument. No lower bound on full curvature, no coordinate-nonzero premise, and no finite-interface hypothesis is used.
- `FixedNormalTangentialStrong` proves projected strong supporting inequalities for an arbitrary actual linear map, and specializes the actual BFGS displacement budget to it. With the tangent map this is exactly U.16. Actual support monotonicity and the optimizer-plane lemma need only this projected curvature. Summability or full displacement convergence is not assumed or asserted by these preliminary declarations.
- `FixedNormalCompositeCalculus` derives a supporting vector for the convex remainder by a one-sided convex-chord derivative argument. Full-objective differentiability is absent: every actual supporting vector splits correctly. A scalar function constant in tangent directions has only normal supporting vectors, which gives the original common projection. The scalar contribution's support monotonicity and the smooth summand's derived compact cocoercivity give exact U.17 for arbitrary actual endpoint supports. The full objective's projected strong convexity follows by adding the convex scalar summand on the same structural domain.
- `FixedNormalCompositeSmooth` states scalar local C1,1 using the actual scalar Fréchet derivative, and proves actual local C1,1 for the full locally represented composite off its exceptional levels. It derives the full derivative as the smooth derivative plus the scalar derivative composed with the actual normal functional; local Lipschitz constants are composed and added. No differentiability of the scalar summand at an interface is assumed.
