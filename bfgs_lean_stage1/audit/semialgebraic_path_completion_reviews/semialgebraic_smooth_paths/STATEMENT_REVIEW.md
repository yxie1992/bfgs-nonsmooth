# Actual semialgebraic finite-piece-smooth paths and cylindrical cells

Seven frozen source modules build actual path witnesses carrying both analytic regularity and the semialgebraicity of their restricted parameter graphs. The final import is `SemialgebraicSmoothPathTargets`; the three exact contracts cover composition, mapping, and every literal ordered graph/gap cell. The audit reports every owned declaration, including the enriched structure's constructor and both fields, and six strict source/wrapper comparisons. Reproduce with `bash audit/scratch/semialgebraic_smooth_paths/verify.sh`.

`SemialgebraicPiecewiseSmoothPath` contains an actual `PiecewiseSmoothPath` and a proof that `{(t,p(t)) | 0 ≤ t ≤ 1}` in the literal Option coordinates is semialgebraic. It retains the original continuous-on-interval curve, exact endpoints, image containment, and smoothness at every interior time outside a finite exceptional set. No condition is imposed on an arbitrary extension outside the parameter interval.

Five concrete analytic witness constructors keep the exact constant, reversed, concatenated, mapped, and affine-segment formulas. This prevents an invalid step of selecting an arbitrary smooth path from an opaque existence theorem and assuming its graph is semialgebraic. The separately proved actual graph calculus attaches semialgebraicity to those exact curves. Concatenation inserts the midpoint into the finite exception set and scales both previous exception sets. Mapping requires actual smoothness on the path set and an actual semialgebraic restricted map graph; the larger-domain variant lets a global polynomial map act on a path lying in an arbitrary smaller set.

The enriched connectivity relation has actual reflexivity, symmetry, transitivity, and image/convex/graph constructors, and forgets to the previously verified ordinary piecewise-smooth relation. The graph lift uses the literal Option output coordinate and preserves the original restricted graph. Vertical fibers require only convexity: their connecting paths are affine segments mapped by a global polynomial embedding, so target-fiber semialgebraicity is not silently assumed.

The band constructions concatenate two such vertical paths and the actual lifted base path. The midpoint and offset sections are both smooth and have semialgebraic restricted graphs derived by the scalar graph arithmetic. The finite ordered-cell theorem uses the exact existing graph and all-boundary-inequality gap definitions in Option coordinates. It handles zero boundaries with the full cylinder, the lower and upper tails, and every interior consecutive gap. Neither full-dimensionality nor nonempty base/fibers is assumed.

The final ordered-cell contract still explicitly requires a semialgebraic base, actual enriched paths in that base, actual smooth restricted boundary functions, actual boundary graphs, and strict ordering. The separately constructed dimension induction will discharge these hypotheses for arbitrary semialgebraic sets. This scope alone does not claim a global decomposition, ordinary-component equivalence, or a generic path-selection oracle. It supplies the stronger literal semialgebraic witness-path requirement in Module A, beyond the already verified finite-critical-values argument.
