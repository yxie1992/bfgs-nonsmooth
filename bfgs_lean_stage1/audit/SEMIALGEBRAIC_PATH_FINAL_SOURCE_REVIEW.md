## Path regularity, endpoints and composition

The precise interval statement is continuity on the closed interval, with `ContDiffAt ℝ ∞` at every interior time outside a finite exceptional set. This implies the piecewise-C1 regularity used in A's differentiation argument. It does **not** assert derivatives at the path endpoints, continuous derivative extensions across break points, finite one-sided derivatives there, or a uniform derivative bound. None of those stronger assertions is used to obtain constancy. The finite exceptional set can include endpoints and all internal junctions; continuity joins the constant values on the intervening pieces.

The source phrase “piecewise C1” should retain this explicit meaning. Reading it as a requirement that every piece extend C1 to both of its closed endpoints would be stronger than the proved statement and is not being claimed.

`generalSemialgebraicPathCover` concludes the literal semialgebraicity of each witnessing graph on `[0,1]`; it does not merely give a smooth path inside an SA set. Its finite cover is constructed by checked real-polynomial sign/degree/root refinements, graph/gap cell constructors and dimension induction. No assumed decomposition, path oracle or external quantifier-elimination axiom survives.

`convex_semialgebraic_objective_curve_piecewise_smooth` takes the actual continuous semialgebraic curve and a finite convex semialgebraic objective. It proves the actual restricted graph of `F ∘ p` semialgebraic, its continuity including endpoints, and its C-infinity regularity away from finitely many interior parameters. The point curve need not be differentiable as an input. In particular, neither differentiability of F at the path points nor smoothness of its subgradient selection is assumed. The scalar regularity theorem itself is stronger: a genuine restricted scalar graph on any actual real domain is smooth on that domain outside a derived finite set.

An arbitrary smooth curve need not have a semialgebraic graph, so the composition theorem is not applied to C's arbitrary smooth paths by silently adding that premise. C's separate `semialgebraic_affine_critical_path_constant` obtains constancy from the independently proved finite critical-value set and actual critical path connectivity. The resulting composition is then constant on the whole interval and has zero derivative at every interior time, including the point curve's exceptional times.
