# A ordinary path calculus and bounded supporting representation

This frozen five-file scope contains 14 explicit declarations. It proves the ordinary calculus, finite-dimensional affine algebra, and finite-image order arguments in the proof of `A:semialgebraic`. It does **not** prove the real-algebraic projection or finite differentiable path-decomposition ingredients. No unconditional semialgebraic source target is claimed.

`AffineSupportPath` proves that every actual global support g at p(t) pairs with the actual derivative p'(t) to give the derivative of F∘p, whenever both two-sided derivatives exist. It applies Fermat's theorem to F(p(u))−g·(p(u)−p(t)), whose global minimum at t follows from the actual supporting inequality. The objective itself need not be differentiable at p(t). Every actual support has the same pairing, so actual affine-hull membership of zero forces that pairing, and hence the derivative of F∘p, to vanish.

`AffinePathConstancy` proves constancy on a closed interval when the actual derivative vanishes in its interior outside a finite set. It splits the interval at each exceptional point and inducts on that finite set. Only continuity is used at endpoints and corners. For a finite convex objective, actual objective continuity is derived, so a continuous path lying in the actual affine-critical set is constant in objective value when the path and its composition are differentiable outside finitely many times. No existence or regularity of such paths is inferred from semialgebraicity here.

`FiniteAffineCriticalValues` derives a positive gap above any real value in an arbitrary finite real set. It uses isolation from the finite set with that value removed; the proof includes empty sets and the case with no larger value. The actual finite-critical-image specialization plus an attained minimum yields zero in the actual supporting subdifferential at low-level affine-critical points. The finite critical-value image is an explicit premise of this conditional theorem.

`AffineBoundedRepresentation` uses an actual maximal affinely independent subset of the original set, its proved finite-dimensional cardinal bound, and an actual affine combination. This yields a positive number m≤n+1 of members of the original set and signed coefficients summing to one. There is no nonnegative-coefficient premise and no rank hypothesis on the original set. The resulting equivalence describes the actual affine-critical predicate using at most n+1 actual global supports. This includes dimension zero and arbitrary nonsmooth subdifferentials. No convex Carathéodory substitution or external elimination computation is used.

`AffineCriticalPathCover` makes the missing geometric input explicit: a finite cover of the actual affine-critical set by pieces in which each pair of points is joined by a supplied continuous path with finitely many derivative exceptions for both the path and the objective composition. Each piece has a singleton-or-empty objective image, so their finite union has finite objective image, and the low-level consequence follows. Empty pieces and empty covers are handled. This predicate is deliberately named for the path property; it is not used as a definition of semialgebraicity.
