# Constructive local stable-orbit criterion

This six-module unit supplies the nonlinear dynamics existence theorem needed by Module L. It is an independently verified criterion; its hypotheses must still be discharged for L's actual normalized return map. It does not assume a stable manifold, a convergent orbit, a BFGS matrix limit, or an externally computed eigendecomposition.

For complete real normed spaces S and U, a map T fixes zero and has the actual strict derivative A × L there, with A a continuous linear contraction and L an invertible continuous linear map whose inverse is a contraction. Every sufficiently small prescribed stable initial coordinate then extends to an actual forward orbit of T that stays in any prescribed ball and converges to zero. These hypotheses imply the conclusion without a global regularity assumption on T. The finite-dimensional exact targets use S = R² and U = R³, with the ordinary Pi/product norms.

The proof constructs a contraction on a closed ball in C₀(N,S × U). Its stable coordinate is initialized by the prescribed value; subsequent stable coordinates use the forward recurrence. Its unstable coordinate uses the backward recurrence L⁻¹(u(n+1) − N(w(n))). Continuity of N at zero and N(0)=0 ensure that this operator actually maps sequences tending to zero to such sequences. The actual local strict derivative gives a two-point Lipschitz bound for N = T − DT(0) on a small closed ball. The two operator estimates give invariance and a contraction constant strictly below one. Banach's theorem therefore constructs a fixed point in that ball; applying L converts its backward coordinate equation into the desired forward recurrence. Convergence follows from the constructed fixed point's membership in C₀. It is not an input orbit assumption.

The positive-direction result chooses a small positive multiple of any stable vector on which a given linear functional is positive. It proves that functional is positive at the initial orbit point. Positivity at every later physical L scale remains a separate consequence of the actual equation tau(next)=tau*r and the already derived positive return factor on L's implementation neighborhood. The criterion's exact targets deliberately retain the strict derivative and contraction hypotheses; an exact BFGS application requires the actual derivative splitting and oracle agreement.
